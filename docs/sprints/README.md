## 📊 Estructura de Cada Sprint

Cada carpeta de sprint debe contener:

```
sprint-X/
├── planning.md          # Planificación del sprint
├── user-stories.md      # User stories detalladas con tareas
├── progress.md          # Seguimiento diario
└── retrospective.md     # Retrospectiva final
```

### planning.md
- Objetivo del sprint
- User stories seleccionadas
- Métricas y team
- Definition of Done
- Arquitectura técnica
- Planning detallado por semana
- Impedimentos potenciales
- Criterios de éxito

### user-stories.md
- Descripción detallada de cada user story
- Criterios de aceptación
- Tareas técnicas con estimaciones
- Ramas de Git asociadas
- Tabla resumen de tareas

### progress.md
- Estado general
- Progress diario (daily standups)
- Tareas completadas/en progreso/pendientes
- Burndown chart
- Blockers e impedimentos
- Notas del sprint

### retrospective.md
- Métricas finales
- Qué funcionó bien
- Qué no funcionó
- Ideas de mejora
- Acciones para siguiente sprint
- Logros destacados
